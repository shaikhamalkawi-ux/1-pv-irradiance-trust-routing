# Qatar data and event-registry boundary

The Qatar irradiance telemetry and owner-maintained sensor-event registry are confidential / owner-controlled and are not redistributed here.

Only disclosure-safe objects may be published, such as coded sensor identifiers, fit/calibration/test date boundaries, membership/rule specifications, derived trust scores approved for release, aggregate metrics, and provenance hashes.

Owner confirmation remains authoritative for the meaning and publication-safe wording of calibration removals, tracker misalignment, reported sensor issues, pending constants, and sensor naming.
